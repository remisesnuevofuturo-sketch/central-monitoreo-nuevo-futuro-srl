# Central Nuevo Futuro 0.11.0
Se conserva la base 0.10.0. Node 20+, sin dependencias de ejecución.
`npm start` ejecuta server.js; `npm test` ejecuta integración y regresiones.
Mantener NF_TOKEN, configurar NF_ADMIN_TOKEN distinto, DATA_DIR y NODE_ENV=production para HTTPS.
El servidor agrega fleet.js (solicitudes y cámara del camino) y mantiene operations.js.
No publicar sin autorización. Respaldar los JSON de DATA_DIR; Render gratuito no es almacenamiento durable.
Leer INSTALACION_0_11_0.md e INFORME_0_11_0.md de la entrega completa antes de actualizar.
